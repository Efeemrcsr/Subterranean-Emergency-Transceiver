# Subterranean Emergency Transceiver System

## Overview
A discrete analog and RF circuit design challenge aimed at building a robust subterranean emergency transceiver system. All circuits were designed, modeled, and simulated using LTspice.

## System Architecture
The project consists of several specialized circuit stages:
* **TTE Low-Frequency Transmitter:** Designed for Through-Earth transmission.
* **Automated Seismic Warning:** An analog loop to detect and alert seismic activity.
* **VHF Airband Receiver:** For receiving airband distress/communication signals.
* **Low-Noise Analog Baseband:** Signal conditioning and amplification stage.

## Tools Used
* LTspice (Circuit Simulation & Analysis)
* Passive RLC networks, Op-Amps, BJT/MOSFET transistors
